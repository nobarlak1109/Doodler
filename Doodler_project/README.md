# 낙서장

## 실행

`index.html`을 Chrome 또는 Edge에서 여세요. 설치, 서버, 인터넷 연결 없이 실행됩니다. index.html, topics.js, script.js, style.css를 같은 폴더에 두세요.

## 사용

- 모든 화면 상단의 후기 배너에서 Google 설문 링크를 새 탭으로 열 수 있습니다. 회원 가입 및 활동 후 후기를 남기면 추첨을 통해 커피 쿠폰을 받을 수 있습니다. 설문 참여에는 인터넷 연결이 필요합니다.
- 오늘의 주제는 한국 시간 자정에 바뀌며, 일상·추억·취향을 담은 주제 50개가 하루에 하나씩 순환합니다. 열어 둔 화면도 갱신되며, 절전 후 돌아오면 날짜를 다시 확인합니다. 시작한 그림은 원래 주제와 날짜를 유지합니다. 첫 선부터 3분이 시작돼요. 화면을 옮겨도 시간이 흐르고, 시간이 끝나면 그림이 저장됩니다.
- 오늘의 주제, 자유 연습, 세 가지 모양으로 그리는 조건 추가을 선택할 수 있어요. 시작한 그림은 먼저 완성해 주세요.
- 펜·채우기·스프레이·직선·원·사각형을 선택할 수 있어요. 원은 중심에서 바깥으로, 직선과 사각형은 시작점에서 끝점까지 끌어 그립니다. 색상·굵기·지우개·되돌리기·다시 실행·모두 지우기도 사용할 수 있어요.
- 채우기는 누른 지점과 연결된 비슷한 색의 영역에 적용됩니다. 스프레이는 누르고 있는 동안 분사되고 굵기로 범위를 조정합니다. 선택적으로 짧은 메모를 남길 수 있어요.
- 나의 기록에서 날짜별 그림을 보고 주제/모드로 골라 볼 수 있어요. 그림이나 카드를 PNG로 내려받거나 그림을 삭제할 수 있어요. 기존 그림에서 조건 추가을 시작하면 두 버전을 비교할 수 있어요.
- 오늘의 주제을 완성하면 이번 주 기록에 표시됩니다. 연습과 조건 추가은 완료 표시에 포함되지 않아요.
- 그리던 그림은 임시 저장됩니다. 복원할 때도 실제 시간이 반영되므로 3분이 지났다면 자동으로 완성됩니다.

그림·임시 그림·예시 하트는 이 브라우저에 저장됩니다. 브라우저 데이터 삭제 또는 저장 제한으로 기록이 사라질 수 있으니 중요한 그림은 내려받아 주세요. 저장 실패 시 현재 탭에서는 계속 사용할 수 있습니다. 갤러리의 여섯 그림과 기본 하트 수는 예시입니다. 프로필 찾기는 Supabase 설정 시 실제 아이디·닉네임·소개를 검색하며, 미설정 시에만 예시 프로필을 보여줍니다. 소개에서 프로젝트 목적·개발진·향후 방향을 확인할 수 있습니다.

## 선택 기능: 온라인 커뮤니티

`커뮤니티` 탭은 Supabase용 로그인·프로필·클라우드 그림·공개 갤러리·좋아요·팔로우를 제공합니다. 상단 `프로필 찾기`에서도 실제 프로필 검색·팔로우와 해당 사용자의 공개 그림 보기가 가능합니다. Supabase 설정 전에는 온라인 기능이 비활성화됩니다. 사용자 설정을 사용한 실제 공개 그림 조회는 확인했으며, 두 계정 권한 검증은 아직 필요합니다. [연결 및 Vercel 배포 절차](backend/SETUP.md)를 확인하세요.

그림을 직접 선택해야 업로드되며 기본값은 나만 보기입니다. 클라우드 그림은 기존 브라우저 기록과 별도로 표시됩니다. 로컬 그림이나 임시 그림을 자동 업로드하지 않습니다. 전체 공개한 그림·메모와 프로필은 누구나 볼 수 있습니다. 새로고침 시 다시 로그인해야 합니다. 기존 갤러리는 계속 예시 화면이며 실제 공개 그림은 커뮤니티에서 볼 수 있습니다.

## 수정과 확인

script.js의 `DURATION`은 제한 시간, `colors`는 색상입니다. style.css에서 테마와 레이아웃을 조정할 수 있습니다.

주제는 별도 파일 [topics.js](topics.js)의 `DOODLER_TOPICS` 배열에서 관리합니다. 익숙한 일상 장면, 개인의 기억과 취향, 간단한 선택을 묻는 상황을 중심으로 구성합니다. 짧은 제목과 구체적인 질문으로 각자의 경험을 한 장면이나 물건으로 표현하도록 안내합니다. 고유하고 제목의 뜻에 맞는 `id`, 표시할 `title`, 안내 문구 `description`을 가진 항목을 추가하세요. 발행한 주제의 ID는 이후 유지하고, 다른 내용의 주제에는 새 ID를 사용하세요. 목록은 최소 하나의 항목을 유지해야 합니다. 예:

```js
{id:'favorite-song-scene', title:'자주 듣는 노래', description:'좋아하는 노래를 들을 때 떠오르는 장면을 그려보세요.'}
```

`dailyTopic(day)`는 한국 날짜의 일수에 목록 길이로 나머지 연산을 적용해 주제를 고릅니다. 같은 목록과 날짜에는 항상 같은 주제가 선택되며, 목록 길이만큼의 날짜 후 반복합니다. 목록의 길이나 순서를 바꾸면 오늘과 이후 날짜의 선택이 바뀔 수 있습니다. 저장된 그림과 진행 중인 그림의 주제는 유지됩니다. `updateDailyTopic()`이 화면을 갱신하고 `scheduleDailyTopicUpdate()`가 다음 한국 시간 자정에 실행을 예약합니다. 기기 시계를 사용하며 서버의 주제 일정과 연결되지는 않습니다. 파일을 수정한 뒤 새로고침하고, 배포 시 topics.js도 포함하세요.

온라인 연동 코드는 `node --check social-api.js`, `node --check social-ui.js`, `node --test tests/social-api.cjs`로 확인합니다. 브라우저 검증에는 모의 서버를 사용하는 커뮤니티 검사도 포함됩니다. 실제 Supabase 인증·RLS·저장소 권한 검증은 아직 수행하지 않았습니다.

`node --check topics.js`와 `node --check script.js`로 문법을 확인합니다. Node 24와 Windows의 Chrome이 있으면 `node tests/run.cjs`로 별도 임시 프로필에서 브라우저 검증과 화면 캡처를 실행할 수 있습니다. 물리적인 모바일 기기와 Edge, 접근성 검증은 별도로 진행해야 합니다.
