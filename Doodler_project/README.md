# 낙서장

## 실행

`index.html`을 Chrome 또는 Edge에서 여세요. 설치, 서버, 인터넷 연결 없이 실행됩니다. index.html, script.js, style.css를 같은 폴더에 두세요.

## 사용

- 오늘의 주제는 한국 시간 자정에 바뀌며, 일곱 주제가 매주 순환합니다. 첫 선부터 3분이 시작돼요. 화면을 옮겨도 시간이 흐르고, 시간이 끝나면 그림이 저장됩니다.
- 오늘의 주제, 자유 연습, 세 가지 모양으로 그리는 조건 추가을 선택할 수 있어요. 시작한 그림은 먼저 완성해 주세요.
- 펜·채우기·스프레이·직선·원·사각형을 선택할 수 있어요. 원은 중심에서 바깥으로, 직선과 사각형은 시작점에서 끝점까지 끌어 그립니다. 색상·굵기·지우개·되돌리기·다시 실행·모두 지우기도 사용할 수 있어요.
- 채우기는 누른 지점과 연결된 비슷한 색의 영역에 적용됩니다. 스프레이는 누르고 있는 동안 분사되고 굵기로 범위를 조정합니다. 선택적으로 짧은 메모를 남길 수 있어요.
- 나의 기록에서 날짜별 그림을 보고 주제/모드로 골라 볼 수 있어요. 그림이나 카드를 PNG로 내려받거나 그림을 삭제할 수 있어요. 기존 그림에서 조건 추가을 시작하면 두 버전을 비교할 수 있어요.
- 오늘의 주제을 완성하면 이번 주 기록에 표시됩니다. 연습과 조건 추가은 완료 표시에 포함되지 않아요.
- 그리던 그림은 임시 저장됩니다. 복원할 때도 실제 시간이 반영되므로 3분이 지났다면 자동으로 완성됩니다.

그림·임시 그림·하트는 이 브라우저에 저장됩니다. 브라우저 데이터 삭제 또는 저장 제한으로 기록이 사라질 수 있으니 중요한 그림은 내려받아 주세요. 저장 실패 시 현재 탭에서는 계속 사용할 수 있습니다. 갤러리의 여섯 그림과 기본 하트 수, 프로필 찾기의 네 프로필은 예시입니다. 프로필 찾기에서는 예시 닉네임·아이디·관심 주제를 검색하고 예시 그림을 볼 수 있어요. 소개에서 프로젝트 목적·개발진·향후 방향을 확인할 수 있습니다. 로그인·실제 사용자 검색·다른 사용자와 공유·서버는 아직 없습니다.

## 수정과 확인

script.js의 `DURATION`은 제한 시간, `topics`는 주제, `colors`는 색상입니다. style.css에서 테마와 레이아웃을 조정할 수 있습니다.

`node --check script.js`로 문법을 확인합니다. Node 24와 Windows의 Chrome이 있으면 `node tests/run.cjs`로 별도 임시 프로필에서 브라우저 검증과 화면 캡처를 실행할 수 있습니다. 물리적인 모바일 기기와 Edge, 접근성 검증은 별도로 진행해야 합니다.
